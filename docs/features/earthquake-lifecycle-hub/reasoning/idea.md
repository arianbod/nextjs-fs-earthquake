# Core Idea: earthquake-lifecycle-hub

## The Idea

A comprehensive **Safety Hub** that guides users through the complete earthquake lifecycle:

1. **Before Earthquake** - Preparedness checklists, emergency kit guides, family safety plans, and connection to their existing building assessment
2. **During Earthquake** - Real-time safety instructions (DROP-COVER-HOLD ON), accessible offline, with audio/visual guidance
3. **After Earthquake** - Photo-based damage assessment using AI, recovery resources, and connection to reassessment flow

This transforms QuakeWise from a one-time assessment tool into a **continuous safety companion**.

---

## Problem It Solves

Users complete building assessments but then face:
- **No guidance** on what to do before an earthquake occurs
- **Panic during** earthquakes - need clear, accessible instructions
- **Uncertainty after** - how to assess damage, whether building is still safe
- **Disconnect** between their assessment data and actionable safety steps

## Scope

### In Scope (MVP)
- **Before Phase:**
  - Interactive preparedness checklist (sourced from AFAD/FEMA)
  - Emergency kit guide with quantities
  - Family communication plan template
  - Connection to user's building risk level
  - Printable PDF export

- **During Phase:**
  - Full-screen safety instructions
  - DROP-COVER-HOLD ON guidance
  - Audio playback option
  - Completely offline-capable
  - Accessibility compliant

- **After Phase:**
  - Photo upload for damage assessment
  - AI-powered damage analysis (reuse existing)
  - Severity classification
  - Link to reassessment flow
  - Recovery resources for Turkey

### Out of Scope
- Real-time earthquake detection (exists in Alerts feature)
- Family check-in system (separate future feature)
- Insurance claim processing
- Professional engineering verification
- Multi-hazard (tsunami, fire) - future expansion
- Community damage aggregation map - future

### MVP Version
1. Static content for all three phases
2. Interactive checklist with progress saving
3. Photo damage assessment with AI
4. Full i18n (EN/TR)
5. Responsive (mobile-first for crisis use)
